audio-sound

A script that runs, plays and saves here: the editor's engine and player, with no picture. Press play, or change the script; ⌘↵ in the script plays it, ⌘S saves it; a file dropped on it opens.

Whole

// read by Jothi Tharavant, LibriVox, public domain
audio('voice.mp3')
  .trim()
  .normalize('podcast')
  .save('episode.mp3')

With its picture

The waveform and the spectrogram of what the script comes to, the place it plays on each; a press goes there. In sight, they have the script run.

// Kimiko Ishizaka, public domain, an excerpt
audio('song.mp3')
  .fade(1, 2)

Its parts elsewhere

A part outside its sound names it, as a label names its control.

audio('chime.wav')
  .reverse()
  .fade(0.02, 0.1)

A file alone

An editor as the sound

An embedded editor is a sound too: the page's parts name it, and a code block kept in step with its script by two listeners.

audio('chime.wav')
  .gain(-3)
